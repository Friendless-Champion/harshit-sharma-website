# Harshit Sharma — Portfolio

A motion-led portfolio for robotics engineering, public STEM work, policy research, debate, and mentoring. The site uses semantic HTML, CSS animations, and vanilla JavaScript; it has no build step.

## Local preview

Open `index.html` in a browser, or run a static server in this directory:

```sh
python -m http.server 4174
```

## Pages

- `index.html` — introduction, selected experience previews, about, recognition, and contact.
- `experiences/index.html` — the scroll-synchronized experience stories and a directory of all 11 resume entries.
- `experiences/*.html` — individual detail pages with role-specific information and four photo slots each.
- `resume.html` — a printable, readable resume.
- `styles.css` — layout, responsive art direction, and animation system.
- `script.js` — reading progress and scroll-synchronized experience scenes.
- `build_experience_pages.py` — regenerates the individual static detail pages from their source content.

## Content and privacy

Resume details are used as source material. The downloadable source PDF is not included because it contains a phone number; request a copy by email from the resume page. Check dates and awards before publishing.

## Hosting

This is a static site and can be hosted with GitHub Pages or any static host. No package installation is needed.
